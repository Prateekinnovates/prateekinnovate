ZeroTrace

On-Premise Zombie API Discovery & Forensics  ·  Python  ·  Docker  ·  FastAPI  ·  n8n

A complete on-premise platform for discovering, classifying, and automatically responding to zombie APIs inside Indian bank networks. ZeroTrace runs entirely inside the bank's perimeter — no data leaves, no cloud dependency. It finds forgotten, unauthenticated endpoints that have been sitting exposed for months or years, assigns each a Threat Persona, and generates RBI-compliant forensic evidence reports automatically.

Built for the Union Bank of India PSBs Hackathon Series 2026, competing in PS9 — Zombie API Defence for Cyber Security. Addresses a 62% increase in API attacks on Indian BFSI in H1 2023. Average cost of an API-specific breach in India: ₹3.4 crore. DPDP Act 2023 penalties: up to ₹250 crore. Zero direct incumbent in this market.

KEY CAPABILITIES

  • Behavioral fingerprinting — probes auth, data exposure, method acceptance on every endpoint
  • 4 Threat Personas: Ghost, Sleeper, Relic, Shadow — each with automated n8n response playbooks
  • Honeypot endpoints following bank naming conventions — zero false positives, active attacker detection
  • Blast radius calculation — estimates customer records exposed per vulnerable endpoint
  • Auto-generates RBI & CERT-In forensic evidence packages with Git-traced API biography and kill chain simulation
  • Fully air-gapped deployment — runs inside bank's network, zero external data transfer
  • B2B SaaS — ₹50K to ₹50L/yr targeting 12 PSBs, 21 private banks, 10,000+ NBFCs
